# AUC-2026-002

## Summary

> 서울 강서구 화곡동 아파트. 감정가 5.2억, 최저입찰가 3.64억. 내 입찰가 4.2억으로 응찰했으나 낙찰가 4.25억에 500만원 차이로 패찰.

## Decision

### 입찰 여부

- [ ] 입찰
- [ ] 보류
- [x] 포기 (패찰)

### 판단 이유

- 최대 입찰가 4.2억으로 응찰했으나 4.25억에 낙찰. 500만원 차이로 아쉽게 패찰.

## Analysis

### 1. 권리분석

- 선순위 임차인 없음. 근저당 1건(2.0억).

### 2. 시세분석

- 인근 유사 평형 실거래가 5.0~5.5억. 감정가 5.2억 대비 최저입찰가 비율 70%.

### 3. 수익성 분석

- 예상 낙찰가 4.0억, 대출 70% (2.94억), 이자율 5.5%
- 월세 180만원 → 연 수익 2,160만원
- 연 이자 약 1,617만원 → 연 순수익 약 543만원 (ROI 약 5.1%)
- 낙찰가 4.25억 기준으로는 ROI 3.8%로 떨어짐

### 4. 임장 메모

- 도보 10분에 지하철역, 초등학교 인접. 주거 환경 양호. 리모델링 필요 없음.

## Result

### 결과

- 패찰. 낙찰가 4.25억, 내 최고가 4.2억.

### 낙찰가 / 패찰가 비교

- 낙찰가: 4.25억
- 내 입찰가: 4.2억
- 차이: 500만원 (감정가 대비 81.7% → 감정가 대비 82.7%)
