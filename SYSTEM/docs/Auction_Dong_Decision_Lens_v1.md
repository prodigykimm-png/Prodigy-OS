# Auction Dong Decision Lens v1

동 상세 프로파일의 근거를 경매 검토자가 바로 사용할 수 있는 조건부 판단으로 투영한다.

## 필수 항목

- `position_summary`: 부산·구 안에서 어떤 입지인지 한 문장
- `demand_base`: 실제로 물건을 받아줄 수요 기반
- `works_for`: 이 동에서 상대적으로 검토하기 좋은 물건·주소 조건
- `be_conservative_when`: 가격을 보수적으로 잡아야 하는 조건
- `reject_signals`: 확인되면 입찰 중단 또는 큰 할인 없이는 피할 조건
- `field_questions`: 현장에서 반드시 답해야 할 질문
- `liquidity_note`: 매도·임대 시 누구에게 팔거나 빌려줄지
- `confidence`: `high`, `medium`, `low`
- `basis`: 판단에 사용한 상세 프로파일 필드와 출처

## 표현 원칙

- 동 전체를 좋음·나쁨으로 서열화하지 않는다.
- `들어가도 된다`가 아니라 `어떤 물건·가격·주소 조건이면 검토 가능한지`를 말한다.
- 상가·아파트·다세대·단독·오피스텔의 수요를 섞지 않는다.
- 민간 플랫폼 단지 수는 대표성 경고와 함께 사용한다.
- 주민 표본이 부족하면 생활 체감은 임장 질문으로 전환한다.
- 정비사업은 현재 단계와 구역 포함 여부가 확인될 때만 플러스 요인으로 본다.

## 자동 생성 판단 렌즈

수작업 `deep_profile.auction_decision_lens`가 없는 프로파일은 `AuctionDongProfileCore.decisionLens()`가 이미 저장된 공식 동·권역 근거를 보수적인 경매 질문으로 변환한다.

- 수작업 렌즈를 항상 우선하며 덮어쓰지 않는다.
- 생성 렌즈는 동명, 권역, 구·군 내 역할, 수요 발생원, 변화 요인, 미확인 항목만 사용한다.
- 확신도는 반드시 `low`이고 `basis`에 `generated_conservative_lens`를 기록한다.
- 역·정비사업이 같은 권역에 있다는 사실을 개별 주소의 역세권·사업구역 포함으로 확정하지 않는다.
- 인구·사업체·주택 숫자는 공식 원본 파일의 기준일·행정동 코드·206개 매칭을 검증한 뒤에만 추가한다.

2026-08-30 기준 수작업 렌즈 22개, 공식근거 기반 생성 렌즈 184개로 부산 206개 행정동 전체가 판단 보드에 조건부 결론을 표시한다.
