# 경매 지역 주기지표 운영

## 범위

부산·서울·인천·경기의 83개 시군구 지역노트를 갱신한다. 행정동 영구 기본정보와 분리하며, 값이 없는 지표를 0으로 대체하지 않는다. 실행 순서는 부산 → 서울 → 인천 → 경기다. 데이터별 공식 갱신주기가 다르므로 모든 값을 월간 자료로 간주하지 않는다.

| 데이터 | 공식 원천 | 권장 주기 | 저장값 |
|---|---|---:|---|
| 주민등록 인구·세대 | 행정안전부 주민등록 인구통계 CSV | 월 1회 | 총인구, 남성, 여성, 세대수, 인구·세대 증감 수·YoY, 인구·가구 신호 |
| 매매 시장 | 한국부동산원 R-ONE 공개표 | 실험적 월간 | 3개월 거래량, 가격 YoY, 전세가율 — 일부 지역 결측, 핵심 신호·종합점수에 미사용 |
| 주택 재고 | 한국부동산원 공식 파일 | 연간 또는 공식 파일 개정 시 | 아파트 재고, 파생 회전율 |
| 입주 예정 | 한국부동산원 공식 파일 | 반기 또는 공식 파일 개정 시 | 12·24개월 누적 물량; 36~60개월은 coverage 확보 전 핵심 화면에서 숨김 |
| 경매 낙찰가율 | 미연결 | 자료 계약 확정 후 | 현재 `자료 없음` 유지 |
| 지가 추세 | 별도 지가 파이프라인 | 원천 갱신 시 | 판단보드에서 별도 표시 |

## 인구·가구 신호

월간 판단보드의 핵심 신호는 AI나 종합점수가 아니라 정확한 전년 동월 쌍으로 결정한다. 인구·세대 증감률의 ±0.1%는 잡음 구간으로 취급한다.

- `인구·가구 확대`: 인구와 세대가 모두 0.1% 초과 증가
- `가구 분화`: 인구는 0.1% 초과 감소하고 세대는 0.1% 초과 증가
- `동반 축소`: 인구와 세대가 모두 0.1% 초과 감소
- `정체`: 위 조건에 해당하지 않음
- `자료 부족`: 정확한 전년 동월 비교가 불가능함

인천 행정개편 신설 4개 구처럼 전년 동월 동일 지역이 없으면 이전 행정구역 값을 임의 분할하지 않고 `자료 부족`으로 남긴다.

## 월간 실행

Vault 루트에서 다음 한 명령만 실행한다.

```bash
node SYSTEM/SCRIPTS/region-metrics-pipeline.js --execute
```

실행 순서:

1. 83개 지역의 공식 원천을 수집하고 raw hash와 스냅샷을 보존한다.
2. 한 지역이라도 수집에 실패하면 지역노트 반영을 전부 중단한다.
3. 83개 스냅샷·지역키·단위·출처·coverage를 모두 사전검증한다.
4. 검증이 모두 성공한 경우에만 지역노트 frontmatter, 표시표, 자동 요약, JSON 히스토리를 갱신한다.
5. 실행 영수증을 `SYSTEM/CACHE/region-metrics/_shared/last-pipeline.json`에 기록한다.

## 점검과 재반영

현재 캐시를 쓰지 않고 계획만 확인:

```bash
node SYSTEM/SCRIPTS/region-metrics-collect-all.js --dry-run
```

수집을 생략하고 저장된 최신 스냅샷의 반영 가능 여부 확인:

```bash
node SYSTEM/SCRIPTS/region-metrics-pipeline.js --dry-run --skip-collect
```

저장된 최신 스냅샷을 다시 반영:

```bash
node SYSTEM/SCRIPTS/region-metrics-pipeline.js --execute --skip-collect
```

동일 원본 hash와 기준월을 다시 반영해도 JSON 히스토리에는 중복 스냅샷을 만들지 않는다. 사람이 작성한 지역 설명과 행정동 영구 기본정보는 이 파이프라인이 수정하지 않는다.

## 사람 검증

자동 수집값은 항상 `verification_status: unverified`로 저장된다. 판단보드에는 기준월·수집일과 함께 노출되며, 공식 원천이 없거나 coverage가 부족한 값은 `자료 없음`으로 남긴다.

## 자동 실행 예시

macOS `launchd`나 CI에서 월 1회 위 실행 명령을 호출하면 된다. 외부 스케줄러는 Vault가 동기화 중이 아닐 때 실행하고, 종료 코드가 0이 아니면 사용자에게 알린다. 스케줄러 설치 자체는 머신별 실행시간 선택이 필요하므로 이 저장소에는 강제 등록하지 않는다.
