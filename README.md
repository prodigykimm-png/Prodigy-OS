# What is Prodigy OS?

Prodigy OS는 단순한 Obsidian Vault가 아니다.

Prodigy OS는 AI와 함께 성장하는 **Personal Operating System**이다.

지식, 투자, 프로젝트, 건강, 경험을 하나의 시스템으로 연결하여

**더 나은 의사결정을 지원하는 것**이 목적이다.

Obsidian는 현재 사용하는 플랫폼일 뿐이며,

Prodigy OS의 핵심은 **데이터 구조, AI, 그리고 의사결정 시스템**이다.

---

# Vision

Prodigy OS는 기록을 위한 시스템이 아니다.

모든 경험은

- 구조화되고
- 연결되고
- 분석되고
- 다시 의사결정에 활용되는

**장기적인 Asset**이 된다.

예를 들어

- 부동산 경매
- 감정평가사 공부
- 웨딩 사진/영상
- 운동
- 독서
- 프로젝트

모든 분야는 하나의 운영체제 안에서 연결된다.

# Philosophy

Prodigy OS는 다음 철학을 따른다.

- Human First
- AI Assist
- Capture First
- Object First
- Data First
- Decision First
- Long-term First

모든 설계는

사용자의 입력을 줄이고

AI의 이해를 높이며

장기 유지보수를 우선한다.

# Architecture

```text
Web Sources
    │
    ▼
Aside Capture
    │
    ▼
Auction Object
├── YAML Property
├── Summary
└── Collected Facts
    │
    ▼
Dashboard
    │
    ▼
Decision (Human Only)
    │
    ▼
Review (Human Only)
```

핵심 원칙:

```
Object stores data.
Dashboard calculates.
AI assists.
Humans decide.
```

# Core Principles
