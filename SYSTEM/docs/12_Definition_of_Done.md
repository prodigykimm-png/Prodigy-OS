# Prodigy OS Definition of Done

## Purpose

Definition of Done defines when operational work is considered complete.

This document is the operational contract for users and AI.

Completion means the Object is reviewable.
It does not mean the Object is perfect.

Operational quality is measured by review readiness.
It is not measured by document length.

---

# Daily Done

Minimum requirements:

- Reflection written
- Change recorded
- Next Experiment recorded
- At least one meaningful Object reference when applicable

Daily does not require long writing.
Consistency is more important than length.

---

# Weekly Done

- Pipeline executed
- Weekly Workspace generated
- Weekly Review read by the user
- Next Week Direction reviewed

Suggested Principles remain pending.
No automatic adoption.

---

# Monthly Done

- Weekly Review Results collected
- Monthly Review generated
- Human validation completed

---

# Auction Done

- Status updated
- Decision Reason recorded
- Review completed after outcome

Site visit remains optional unless required by workflow.

---

# Reading Done

- Reading completed
- Summary recorded
- Learning recorded
- Reflection written

---

# People Done

- Interaction recorded
- Reflection recorded

No forced interaction frequency.

---

# Operational Principles

- Completion means reviewable, not perfect.
- Short evidence is acceptable when it is clear.
- Missing decisions should be visible.
- Suggested Principles remain suggestions until human validation.
- AI may assist with presentation and detection, but humans decide.
