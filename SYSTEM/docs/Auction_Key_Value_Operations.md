# 경매 키값 운영

## 목적

`키값`은 적정가격을 확정하거나 입찰을 권고하는 값이 아니다. 동일 법정동·동일 물건유형의 최근 외부 낙찰사례에서 현재 카드 가격이 어느 위치인지 빠르게 확인하는 기준값이다.

현재 기준선은 AUCT에서 내려받은 부산 오피스텔 최근 1년 CSV다.

## 지역 단위

- 가격 키값: 법정동
- 인구·지역 기본정보: 행정동
- 주기 시장자료: 시군구

가격 비교는 부동산 주소에 직접 포함되고 표본을 덜 분산시키는 법정동을 사용한다. Kakao 지오코딩과 행정동 GIS 매칭은 키값 생성에 사용하지 않는다.

## 계산 계약

```text
전용평수 = 건물면적㎡ / 3.305785
낙찰 평단가 = 낙찰가 / 전용평수
건물 대표값 = 같은 건물 사례의 낙찰 평단가 중앙값
법정동 키값 = 법정동 내 건물 대표값들의 중앙값
```

함께 저장하는 값:

- 전체 사례의 25%·75% 분위수
- 유효 사례 수
- 고유 건물 수
- 기준기간
- 원천
- 신뢰 상태

정식 표시 기준은 유효 사례 5건 이상이면서 고유 건물 3개 이상이다. 기준 미달 값은 삭제하지 않고 `표본 편중` 또는 `표본 부족`으로 표시한다.

평단가 100만 원 미만 또는 1억 원 초과 사례는 원본에 보존하되 `suspicious_unit_price`로 키값 계산에서 제외한다.

## CSV 양식

현재 필수 컬럼은 다음과 같다. 컬럼명은 정확히 유지한다.

```text
물건종류,소재지,대지권,건물면적,낙찰가,매각기일
```

현재 AUCT CSV 양식은 수정 없이 사용할 수 있다.

선택 권장 컬럼:

```text
사건번호,물건번호,상세URL
```

권장 컬럼은 재매각·중복·원본 추적 정확도를 높이지만 현재 키값 생성의 필수값은 아니다. 필수 양식 변경이 필요하면 적용 전에 사용자에게 알린다.

## 재생성

```bash
node SYSTEM/SCRIPTS/auction-key-value-import.js \
  --input '/Users/prodigykim/Downloads/부산_오피스텔_최근1년_매각사례.csv' \
  --output SYSTEM/CACHE/auction-key-value/busan-officetel-2025-09_2026-08
```

출력:

- `normalized.json`: 원본 기반 정규 레코드
- `snapshot.json`: 법정동·유형별 키값
- `audit.json`: 결측·제외·신뢰도 감사

카드용 동기 snapshot은 검증된 `snapshot.json`에서 `SYSTEM/Views/auction-key-value-snapshot.js`로 생성한다. 원본 CSV와 캐시의 기준기간 또는 내용이 바뀌면 카드 snapshot도 함께 재생성해야 한다.

- 기간: 2025-09-02 ~ 2026-08-31

## 카드 표시

오피스텔 카드에서 해당 법정동 그룹이 존재할 때 다음을 표시한다.

- 법정동 키값
- 유효 사례·고유 건물 수
- 예정 입찰가 또는 실제 입찰가 또는 최저가의 전용평당가
- 키값 대비 비율
- `키값 하단`·`키값 근접`·`키값 상단`
- 표본 편중 경고
- hover 시 기준기간·25~75% 범위·원천

현재 가격 위치 구간:

- 90% 미만: 키값 하단
- 90~110%: 키값 근접
- 110% 초과: 키값 상단
